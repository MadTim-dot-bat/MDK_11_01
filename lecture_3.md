# Векторы и строки - Основы C++
Вектор(std::vector) и строка(std::string) - важные базовые контейнеры стандартной библиотеки C++. Они хранят элементы  в непрерывном фрагменте памяти. Оба этих контейнера предоставляют доступ к элементам по индексу и позволяют эффективно добавлять новые элементы в конец.

## Контейнер (std::vector)
В стандартной библиотеке C++ вектором (std::vector) называется динамический массив, обеспечивающий быстрое добавление новых элементов в конец и меняющий свой размер при необходимости. Вектор гарантирует отсутствие утечек памяти. Для работы с вектором нужно подключить файл vector. Элементы вектора должны быть одинакового типа, и этот тип должен быть известен при компиляции программы. Он задаётся в угловых скобках после std::vector (Пример: std::vector<int>).

Само имя std::vector является шаблоном, в который требуется подставить нужные параметры, чтобы получился конкретный тип данных

### Квадратные скобки, функция at

Оказывается, если обратиться по индексу, но вместо обычных круглых скобок, вставить индекс в квадратные, произойдёт магия - код будет уверен в том, что программист всё правильно записал и не будет использовать встроенные валидаторы. Нужно учесть, что если наш криворукий неназванный программист косякнётся в индексах и вставит некорректный индекс, то программа попадёт в неопределённое поведение: Оно будет пытаться прочитать память вектора, не принадлежащее вектору.

Если это не ваш метод, а всё сделать нужно быстро и без какого кипиша - функция at - оно выводит исключение, если косяк в индексе, если же нет - значение под индексом

### Функции front, back и empty

Функции front и back возвращают первый и последний элемент вектора без использования индексов. Функция empty заменяет сравнение data.size() == 0

 Так сложилось, что в стандартной библиотеке индексы и размеры контейнеров имеют беззнаковый тип. Вместо usigned int или unsigned long int используют псевдоним size_t (полное название std::vector<T>::size_type). Size_t совпадает с uint32_t или uint64_t (это зависит от битности платформе). Используют size_t  для подчёркивание того, что мы имеем дело с индексами и/или размером в программе

### Резерв памяти
Вектор хранит элементы в памяти в виде непрерывной последовательности друг за другом. При этом в конце последовательности резервируется дополнительное место для быстрого добавления новых элементов...Короче, Есть в векторах дополнительное место для быстрого сохранения. Если оно занято происходит реаллокация - элемент копируется в новый, более просторный блок памяти и сама процедура очень дорогая. Текущий резерв вектора можно узнать с помощью функции capacity (что означает вместительность и не путайте с size. это размер вектора, а не его вместительность). Иногда требуется заполнить вектор элементами, причём число элементов известно заранее, в таких случаях можно зарезервировать нужный размер памяти с помощью функции reserve (НЕ ПУТАТЬ С RESIZE!!!).
