# Тема: Введение в C++
## Язык программирования C++

Язык программирования C++ представляет высокоуровневый, компилируемый язык программирования общего назначения со статической типизацией. Своими корнями, он уходит в язык C, который был разработан в 1969-1973 годах в компании Belllabs программистом Деннисом Ритчи.

В начале 1980-ых годов, датский программист Бьерн Страуструп, который работал в компании Belllabs, разработал C++ как расширение к C. Фактически в начале C++ просто дополнял язык C с некоторыми возможностями ООП. Изначально язык назывался "С с классами".

С++ является компилируемым языком, а это значит что компилятор транслирует исходных код на С++ в исполняемый файл, который содержит набор машинных инструкций.   

### Основные компиляторы

3. Компилятор от Майкрософт (Visual Studio)

### Состав компилятора G++

### Зачем нужно компилировать исходные файлы?
Исходный С++ файл это всего лишь код, но его невозможно запустить как программу или использовать библиотеку, поэтому каждый исходный файл требуется компилировать в исполняемый

### Этапы компиляции 
1. Предпроцессинг - Макро процессор, который преобразовывает программу для дальнейшего компилирования. На данной стадии происходит работа с предпроцессарными директивами. Например, предпроцессор добавляет Header-ы в код (# include), убирает комментарии. 
2. Компиляция - Преобразование в assembler-ый код. Это промежуточный этап между высокоуровневым языком и машинным кодом.
3. Ассемблирование(чё.) - Перевод assembler-ого кода в машинный.\
Объект файл - созданный assembler-ом промежуточный файл, хранящий кусок машинного кода. Этот кусок машинного кода, который ещё не связан с другими кусками машинного кода, называется объектным кодом
4. Компоновка. Компоновщик (linker) - связывает все объектные файлы и статические библиотеки в единый исполняемый файл, который мы можем запустить.
5. Загрузка. Тут и так понятно
