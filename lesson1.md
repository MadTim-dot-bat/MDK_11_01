# Тема: Жизненный цикл разработки ПО (SDLC): Этапы, виды моделей и их различия

Жизненный цикл – путь, который проходит продукт: От момента задумки до вывода из эксплуатации (Смэрть)

# Этапы жизненного цикла SDLC:
1. Планирование и анализ требований
Эта включает:
+ Описание задач, которые должен решать продукт
+  Опрос стейкхолдеров
+   Выявление аудитории, которая будет пользоваться решением
+ Оценка ресурсов, которые нужны для реализации (количество сотрудников, время, бюджет)
+ Cогласование критериев, по которым будут оценивать успешность решения
Участвуют в данном этапе: Руководитель проекта, владелец продукта, заказчик, бизнес- аналитик и стейкхолдер
ВАЖНО: У каждого этапа может быть своя задача и подзадача


2. Определение требований
Детализация цели и документация её
+ Оценка рисков
+ Выбор методологии работы
+ Описание пользовательских сценариев
Участвуют: руководитель проекта, владелец продукта, команда разработки, архитектор

**Проектирование** – продумывание и запись того, как будут работать те или иные компоненты или всё ПО в принципе 

Высокоуровневое проектирование 	Низкоуровневое проектирование
Основные компоненты системы (Например, модули, сервисы и подсистемы)	Принцип работы отдельных компонентов системы
Принцип взаимодействия этих компонентов между собой	Алгоритмы, структуры данных и логика работы внутри каждого модуля
Общая архитектура системы – например клиент-серверная архитектура или микросервисы 	Детали реализации – например, какие классы, методы или функции будут созданы
Зависимость решение от других систем	Взаимодействие с базами данных API или другими внешними системами 
Прототип интерфейса 	
 Результат: Проектная документация с информацией
3. Разработка
Знаем, чё это и с чем едят…
4. Тестирование
Проверка работы программы по документации и хотелкам заказчика

5. Развёртывание
 Закидывание ПО на платформу, где будут продавать ПО
6. Поддержка и сопровождение
 Обновление ПО по мере её работы и исправление ошибок, и их поступление

7. СМЭРТЬ ПО
Всё, обслуживание закончилось, продукт выведен из эксплуатации 

МОДЕЛИ ЖИЗНЕННОГО ЦИКЛА ПО
- Каскадная (водопадная) модель
Состоит из этапов выше и идут последовательно (устаревший)

Плюсы:
Полное документирование каждого этапа
Минимальные риски
Полная отчётность заказчику



- V-образная модель
- Итеративная модель
-  Инкрементная модель
-   Спиральная модель
- Agile – набор методов для гибкого управление
- Scrum – тоже набор методов :P
- Kanban – подход по созданию структур процессов
